# Page Block Syntax (PBS)

Page Block Syntax (PBS) は、アプリケーション仕様を **ページ単位**で記述し、**レイアウト・フロー・ステート**の3観点で整理する軽量マークアップ言語です。*人→人* と *人→LLM／LLM→人* の情報伝達における曖昧さを最小化し、スパイラル型設計を高速に回すことを目的としています。
